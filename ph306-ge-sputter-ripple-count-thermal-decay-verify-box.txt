Key by hand. Fastest-growing mode of the Bradley-Harper equation: lambda = 2 pi sqrt(2B/|nu_x|), so B(573 K) = 0.1150 x 432.48^2/(8 pi^2) = 272.4 nm^4/s. Beam off: the mode q = 2 pi/lambda decays at B q^4. Mullins: B is proportional to D_s/T, so B(613 K)/B(573 K) = (573.0/613.0) exp[(1.080 eV/k)(1/573.0 - 1/613.0)] = 0.93475 x 4.1672 = 3.8952. B(573 K) q^4 = 2 pi^2 |nu_x|/lambda^2 = 1.2136e-5 1/s; times 3.8952 and 93600 s gives 4.4249; exp(-4.4249) = 0.0120, so 0.012.

Other values. Marginal wavelength 2 pi sqrt(B/|nu_x|) taken for the observed one: 1.4e-4. Only D_s scaled, no 1/T: 0.0088. B kept at its value during sputtering: 0.32. 136 or 138 periods: 0.013 or 0.011.

Short check (Python 3, standard library):
from math import *
lam = 59250/137; r = 573.0/613.0*exp(1.080/8.617333e-5*(1/573.0 - 1/613.0))
