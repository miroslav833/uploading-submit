Key: 132 kN (131.6 kN) minimum breaking load per leg. In the attached notes it is the line "KEY: W taken as 3 t throughout (note 2) ... MBL=131.6 kN" of key.py and "required MBL per leg = 131.56 kN" of independent.py. By hand: the skid (1.6 t) is under 3 t, and DNV-OS-H205 (April 2014) Table 3-1 note 2 on page 18 reads "For objects weighing less than 3 tonnes it is recommended to assume an object weight of 3 tonnes and use this throughout the calculations." Offshore DAF = 1 + 0.25 sqrt(100/3.0) = 2.4434; DHL = 2.4434 x 3.0 x 9.81 = 71.91 kN; leg force 71.91/(2 sin 60) = 41.52 kN; gamma_sf = 1.3 x 1.3 x 1.25 x 1.0 x 1.5 = 3.169; MBL = 3.169 x 41.52 = 131.6 kN. The most tempting wrong answer, 70.2 kN, holds the DAF at 2.4434 but keeps 1.6 t in the load (DHL 38.35 kN, leg 22.14 kN); running the formula at 1.6 t gives 85.5 kN. Check: import math; d=1+0.25*math.sqrt(100/3); print(1.3*1.3*1.25*1.5*d*3*9.81/(2*math.sin(math.radians(60)))) prints 131.56. Source: https://rules.dnv.com/docs/pdf/DNVPM/codes/docs/2014-04/OS-H205.pdf, page 18, Table 3-1 note 2.
