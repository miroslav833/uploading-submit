The record carries one value, the number of beat cycles between the dashed lines A (0.0 ms) and B (620.4 ms), at which the fringe pattern is in the same place. Along the row of camera pixel 100 the intensity maxima are 5.49 ms (8.65 image columns) apart; every tenth one lies near 54.0, 109.2, 163.8, 218.4, 273.7, 328.9, 383.5, 438.2, 493.4, 548.0 and 603.3 ms; per 100 ms after A there are 18, 18, 18, 18, 19, 18 and then 4 up to B: 113 cycles, f = 113/0.6204 s = 182.141 Hz.

Key by hand. Scale factor 4A/(lambda P) = L/(sqrt(3) lambda) = 145980 Hz per rad/s = 0.70773 Hz per deg/h. During the record the ring turns at 259.200 (turntable) + 15.041 sin 48.15 = 11.204 (Earth, vertical part, same sense) = 270.404 deg/h, f_S = 191.373 Hz. The locking equation gives a mean beat sqrt(f_S^2 - f_L^2), so f_L = 58.724 Hz, lock-in rate 82.975 deg/h. Clockwise, the ring turns at 11.204 - Omega_t in inertial space and the beat stops at Omega_t = 82.975 + 11.204 = 94.18 deg/h, that is 94 deg/h (94.05 with a solar-day Earth rate).

The most tempting wrong answer is 31 deg/h, from leaving out the Earth's rotation (f_S = 183.44 Hz, f_L = 21.83 Hz). Other values: the lock-in rate alone 83; counterclockwise threshold 72; first-order pulling formula 95; f = f_S - f_L gives 24; 112 cycles give 101, 114 give 87.

Check in a second (Python 3, standard library):
import math
def thr(N, T=0.6204, L=0.16, lam=632.8e-9, trev=5000.0, lat=48.15, WE=7.2921e-5):
    K = L/(math.sqrt(3)*lam); Wb = WE*math.sin(math.radians(lat))
    fS = K*(2*math.pi/trev + Wb); f = N/T
    if f >= fS: return None
    return (math.sqrt(fS*fS - f*f)/K + Wb)*180/math.pi*3600
print(thr(113), thr(112), thr(114))   # 94.18, 100.94, 86.75
