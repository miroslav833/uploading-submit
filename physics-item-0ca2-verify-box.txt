That is 108 loops, so the dates are 108 orbital periods apart. Per 30 degree sector from 270 down to 90 degrees: 16, 18, 20, 19, 18, 17.

Key by hand. Guiding-centre equations (Dermott and Murray 1981): d theta/dt = -(3/2) n delta and delta^2 = (8/3) mu [C - f(theta)] with f(theta) = 1/(2 sin(theta/2)) - cos(theta). C = f(14.70 deg) = 3.9084 - 0.9673 = 2.9411. Time from 270 to 90 degrees t = (2/(3n)) sqrt(3/(8 mu)) J with J = integral from 90 to 270 deg of d theta / sqrt(C - f) = 2.3971 (integrand 0.6690, 0.7325, 0.8013, 0.8330 at 90, 120, 150, 180 deg, symmetric about 180). With t = 108 x 2 pi/n: mu = J^2/(24 pi^2 108^2) = 2.080e-6, m = mu x 2.745e27 kg = 5.71e21 kg, which is 5.7e21 kg. 107 loops give 5.8e21 kg and 109 give 5.6e21 kg.

Most tempting wrong answer: 6.2e21 kg, from 104 loops, which is what an estimate of the loop spacing by eye tends to give; leaving out the indirect term -cos(theta) gives 2.9e21 kg.

Check program (Python, standard library):

import math
f = lambda t: 1 / (2 * math.sin(t / 2)) - math.cos(t)
C = f(math.radians(14.70))
n = 20000; h = math.pi / n
J = sum((1 if i in (0, n) else 4 if i % 2 else 2) / math.sqrt(C - f(math.pi / 2 + i * h)) for i in range(n + 1)) * h / 3
mu = J**2 / (24 * math.pi**2 * 108**2)
print(J, mu, mu * 2.745e27)        # 2.39711, 2.080e-06, 5.709e+21 kg
