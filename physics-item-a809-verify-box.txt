Key by hand. n = 117 / (5.180 mm)^2 = 117 / 26.83 mm^2 = 4.360 mm^-2. The lens makes the speckle spectrum the intensity on the glass mapped by kappa = k xi / f, so <kappa^2> = k^2 w^2 / (2 f^2) for a Gaussian spot of 1/e^2 radius w. Singularity density of a circular Gaussian field: n = <kappa^2> / (4 pi) = pi w^2 / (2 lambda^2 f^2). w = lambda f sqrt(2 n / pi) = 0.41765 mm^2 x 1.6660 mm^-1 = 0.6958 mm; diameter 1.392 mm, which is 1.4 mm.

Most tempting wrong answer: 0.98 mm, from one singularity per speckle correlation area (n = 1/A_c with A_c = lambda^2 f^2 / (pi w^2)); counting forks of one orientation only, or weighting the spectrum by the amplitude instead of the intensity, gives the same. The radius is 0.70 mm.

Check program (Python, standard library):

import math
n = 117 / (700 * 7.40e-3) ** 2                     # per mm^2
w = 632.8e-6 * 660 * math.sqrt(2 * n / math.pi)    # mm
print(2 * w)                                       # 1.392
print(2 * w / math.sqrt(2))                        # 0.984, one singularity per correlation area
