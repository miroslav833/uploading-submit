By hand. 113 discs and two end plates make 114 gaps, each d = (44.60 - 113 x 0.050)/114 = 0.3417 mm. Only the normal component is dragged; the superfluid stays at rest. In a gap the normal liquid turns with the local angular velocity Omega cosh(kz)/cosh(kd/2), k = (1+i)/delta, delta = sqrt(2 eta/(rho_n omega)), so the liquid acts as a complex moment of inertia J f with J = (pi/2) R^4 rho_n (H - n t) and f = tanh(x)/x, x = (1+i) d/(2 delta). The periods give J Re f = I0 ((T1/T0)^2 - 1) = 6.10e-6 x 0.07234 = 4.413e-7 kg m^2, and (pi/2) R^4 (H - n t) = 9.789e-9 m^5, so rho_n = 45.2 kg/m^3 (after one round for Re f = 0.9964). Then omega = 0.16311 /s, delta = 0.5936 mm, d/delta = 0.576, f = 0.9964 - 0.0550 i. The decrement is pi (1 - T0^2/T1^2) |Im f|/Re f = pi x 0.06746 x 0.05518 = 0.01169, which is 0.012 to two figures. The thin-gap form pi (1 - T0^2/T1^2) d^2/(6 delta^2) gives 0.0117. Any disc number from 110 to 113 gives 0.012.

The most tempting wrong answer is 0.013. It ignores the thickness of the discs altogether: the gap is taken as H/114 = 0.391 mm and the liquid as filling the full 44.60 mm, although the discs fill 5.65 mm of the bore. With the density of the whole liquid, 145 kg/m^3, in the penetration depth one gets 0.038.

A check in Python, standard library only.

import math, cmath
R, H, t, I0, T0, T1, eta, n = 20.00e-3, 44.60e-3, 0.050e-3, 6.10e-6, 37.200, 38.522, 1.30e-6, 113
d = (H - n*t)/(n + 1); w = 2*math.pi/T1; ref = 1.0
for _ in range(20):
    rho = I0*((T1/T0)**2 - 1)/ref/(math.pi/2*R**4*(H - n*t))
    delta = math.sqrt(2*eta/(rho*w)); x = (1 + 1j)*d/(2*delta); f = cmath.tanh(x)/x; ref = f.real
print(rho, delta, f)                                   # 45.24 kg/m3, 5.936e-4 m, 0.99636 - 0.05497j
print(math.pi*(1 - (T0/T1)**2)*abs(f.imag)/f.real)     # 0.011693
