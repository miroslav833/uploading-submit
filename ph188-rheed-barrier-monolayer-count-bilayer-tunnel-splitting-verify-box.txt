Key by hand. Monolayer of GaAs-type (001) = a/2 = 0.2827 nm, b = 71 x 0.2827 = 20.07 nm. With k = sqrt(2 m_w E)/hbar, kappa = sqrt(2 m_b (V0 - E))/hbar, rho = m_w kappa/(m_b k), the even and odd states obey k w = atan(rho T) + atan(rho) with T = tanh(kappa b/2) or coth(kappa b/2). With hbar^2/2m_e = 38.0998 meV nm^2: E_S = 13.5065 meV (k = 0.1541 /nm, kappa = 0.3944 /nm), E_AS = 13.5111 meV, Delta = 4.578 ueV, that is 4.6 ueV. Finite differences with a position-dependent mass agree to 0.1 per cent.

The most tempting wrong answer is 1.7 ueV, from 80 monolayers (80.0 s at a round 1.000 monolayer per second). Other values: 70 monolayers 5.1, 72 give 4.1, 75 (period read at the start only) 2.9; monolayer taken as a: 0.0017; as a/4: 240; psi' matched without the masses: 4.7 ueV.

Check in a second (Python 3, standard library):
import math
def D(N, a=0.5654, w=15.0, V0=92.0, mw=0.067, mb=0.0755, C=38.0998):
    b = N*a/2; out = []
    for odd in (0, 1):
        lo, hi = 1e-9, V0 - 1e-9
        for _ in range(200):
            E = (lo + hi)/2; k = math.sqrt(mw*E/C); q = math.sqrt(mb*(V0 - E)/C); r = mw*q/(mb*k)
            T = 1/math.tanh(q*b/2) if odd else math.tanh(q*b/2)
            lo, hi = (E, hi) if math.atan(r*T) + math.atan(r) - k*w > 0 else (lo, E)
        out.append(E)
    return (out[1] - out[0])*1e3   # ueV
print(D(71), D(70), D(72), D(80))   # 4.58, 5.12, 4.10, 1.68
