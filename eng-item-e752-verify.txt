Key: 16 l/s per m (16.18). It stands in the attached notes in the first section (output line 'KEY q = 16.179 l/s per m') and in the second section (16.179 through the normalisation of Figure 7.16). By hand: L = 9.81 x 81/(2 pi) = 126.466 m, s = 2.80/126.466 = 0.02214. h/Hm0 = 2.14 < 4 (influencing foreshore); d/h = 0.30 < 0.6, mound significant (EurOtop 2018 Eq. 7.12); (d/Hm0)(h/L) = 0.0305 <= 0.65, impulsive (Eq. 7.13); Rc/Hm0 = 1.607 >= 1.35, so Eq. 7.14 on p. 208: q/sqrt(g Hm0^3) = 1.3 (0.30)^0.5 x 0.0014 x (2.80/(6.00 x 0.02214))^0.5 x 1.607^-3 = 0.7120 x 0.0014 x 4.5910 x 0.24090 = 1.1025e-3; x 14.675 = 0.01618 m3/s per m = 16 l/s per m. The most tempting wrong answers are 84 (the EurOtop 2007 composite method with d* and the power -2.9, which the 2018 manual replaced) and 23 (the mound ignored).
