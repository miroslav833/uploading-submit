Key: 120 cm^2/s (119.8). It stands in the attached notes in the output line 'KEY D_z' of the key script, and again in the last line of the independent script. By hand: the first moments at two probes inside the bed differ by L/u, so the liquid's own velocity is u = 40.0/3.20 = 12.5 cm/s and the superficial velocity is V_l = 0.560 x 12.5 = 7.00 cm/s. Kim and Kim, J. Chem. Eng. Japan 16, 172 (1983), Eq. (9): Pe_l = 20.19 (d_p/D_T)^1.66 [V_l/(V_l+V_g)]^1.03 = 20.19 x 0.0200^1.66 x 0.5833^1.03 = 20.19 x 1.5126e-3 x 0.5740 = 0.01753. Their Eq. (8) and nomenclature define Pe_l = d_p V_l/D_z with V the superficial velocity, so D_z = 0.300 x 7.00/0.01753 = 119.8 cm^2/s. Most tempting wrong answer: 210 cm^2/s, from a Peclet number written with the liquid holdup, Pe_l = d_p V_l/(eps_l D), which gives 119.8/0.560 = 214; the paper's definition has no holdup in it.
