Key by hand. lambda = 335.6 km / 53 = 6.332 km, k = 9.923e-4 1/m. l1 = 0.01420/11.40 = 1.2456e-3 1/m, l2 = 0.00580/11.40 = 5.088e-4 1/m. m1 = sqrt(l1^2 - k^2) = 7.530e-4 1/m, m2 = sqrt(k^2 - l2^2) = 8.519e-4 1/m. Matching w = sin(m1 z) below H to exp(-m2 (z - H)) above gives m1 cot(m1 H) = -m2, lowest root m1 H = pi - arctan(m1/m2) = 2.4178, H = 3211 m, so 3.2 km.
Most tempting wrong answer: an overcount from reading the spacing near B as 5.5 to 6 px. 58 wavelengths give lambda = 5.786 km and H = 4.220 km (4.2 km); 59 give 5.688 km and 4.535 km (4.5 km). Neighbouring counts: 54 give 3.363 km (3.4 km), 52 give 3.075 km (3.1 km).
