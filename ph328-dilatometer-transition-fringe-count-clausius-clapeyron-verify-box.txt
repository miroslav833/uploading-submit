Key by hand: normal incidence on the moving face, so lambda/2 per cycle: dL = 113.46 x 632.99e-9/2 = 35.910e-6 m; eps = 35.910e-6/17.000e-3 = 2.1123e-3; dV/V = (1 + eps)^3 - 1 = 6.3504e-3; dTt/dp = Tt (dV/V)/(rho dh) = 331.7 x 6.3504e-3/(7630 x 3540) = 7.799e-8 K/Pa = +78 K/GPa.
