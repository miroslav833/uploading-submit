Key: 1740 t smallest rated crane capacity. In the attached notes it is the line "KEY 20 %/10 % of (B + C) ... -> 1740.0 t" of key.py and "smallest C meeting both conditions: 1740.00 t" of independent.py. DNV-OS-H204 (November 2013) Sec.4 [3.2.6] guidance note, page 25: combined spare buoyancy and spare crane capacity not less than 20 % (ULS) and 10 % (ALS) of the combined object total buoyancy and crane capacity. Intact: 860 + C - 672 >= 0.20 (7900 + C), 0.8 C >= 1392, C >= 1740 t. Damaged: 860 + C - 1052 >= 0.10 (7520 + C), 0.9 C >= 944, C >= 1049 t. Intact governs. The most tempting wrong answer, 602 t, uses the ballast-only 10 %/5 % of [3.2.5]: intact 0.10 x 7900 + 672 - 860 = 602 t. Check: print(max((0.2*7900+672-860)/0.8, (0.1*7520+1052-860)/0.9)) prints 1740.0. Source: https://rules.dnv.com/docs/pdf/DNVPM/codes/docs/2013-11/OS-H204.pdf, page 25.
