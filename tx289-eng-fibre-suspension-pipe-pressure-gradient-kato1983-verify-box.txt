Key: 0.42 % (fibre volume concentration). In the attached notes it is the line 'KEY: C = 0.4204 vol%' of the first script; the second script, by numerical flow-rate integration and a secant search, prints 0.4204. The model is that of Kato and Mizunuma, Bull. JSME 26, 231 (1983): u+ = F2{y_w+/(1+eta_spT), 20, kappa}, F2 = (1/kappa) ln y+ + 0.60 x 20 - (ln 20 - 0.40)/kappa (Eqs. 16, 19, 20, pp. 235-236); eta_spT = 4.2e-9 (l/d)^3.6 C {1 - 2.7e-3 (l/d) C + 2.4e-6 (l/d)^2 C}; 1/kappa = 2.5 + (E/rho V^2)^0.35 G; G = 5.0e-5 (C + 0.18 C^2){0.81 (l/d) + 3.2e-3 (l/d)^2 + 770 e^g}/(1 + e^g); g = {0.096 (l/d) - 24}|0.096 (l/d) - 24|^-0.4 (Eqs. 22-26, p. 236), C in per cent. By hand: the area mean of the log layer gives V/u_t = (1/kappa)[ln(R_w+/(1+eta)) - 1.5] + 12 - (ln 20 - 0.40)/kappa and dp/dx = 4 rho u_t^2/D. Newtonian: 201.8 Pa/m. At C = 0.4204 %: eta = 0.02097, G = 0.002488, (E/rho V^2)^0.35 = 243.7, 1/kappa = 3.106, u_t = 0.04708 m/s, R_w+ = 1200.6, V/u_t = 21.24, dp/dx = 173.2 Pa/m. The most tempting wrong answer, 0.41 %, comes from leaving eta_spT out of y_w+; a slip writing the averaging term as -3.75 gives 0.28 %. Check program (standard library): import math; R,V,L,E=.0256,1.,95.,6.6e9; g=(.096*L-24)*abs(.096*L-24)**-.4; f=lambda C:(lambda eta,ik:(lambda ut:4000*ut*ut/.0512)(next(u for u in [x/1e6 for x in range(30000,70000)] if ik*(math.log(u*R/1.004e-6/(1+eta))-1.5)+12-(math.log(20)-.4)*ik>=V/u)))(4.2e-9*L**3.6*C*(1-2.7e-3*L*C+2.4e-6*L*L*C),2.5+(E/1000/V/V)**.35*5e-5*(C+.18*C*C)*(.81*L+3.2e-3*L*L+770*math.exp(g))/(1+math.exp(g))); print([round(f(c),1) for c in (.41,.42,.43)])  prints dp/dx 173.9, 173.2, 172.6 Pa/m, so 173.2 falls at 0.42 %.
