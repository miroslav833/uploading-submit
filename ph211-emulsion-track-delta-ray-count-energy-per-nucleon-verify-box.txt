By hand. The sinking during exposure is 42.0 x 2.40 = 100.8 um, so L = sqrt(262.0^2 + 100.8^2) = 280.72 um and dN/dx = 88/L = 3.1348e5 per m. For a spinless charge, dN/dx = (2 pi r_e^2 m_e c^2 n_e Z^2/beta^2) [1/T_min - 1/T_max - (beta^2/T_max) ln(T_max/T_min)] with T_max = 2 m_e c^2 beta^2 gamma^2; 2 pi r_e^2 m_e c^2 n_e = 2.6617e4 keV/m and Z^2 = 100. The solution is beta = 0.4919, gamma = 1.1486, T_max = 326.2 keV, bracket 0.028498 per keV, so 931.5 (gamma - 1) = 138.4 MeV per nucleon, 140 to two digits. Counts 86 to 89 all give 140.

The most tempting wrong answer is 150 MeV per nucleon, from dropping the -beta^2 T/T_max term (150.8). Only 1/T_min gives 170; no dip correction, or the dip without the factor 2.40, gives 130; a count of 98 gives 120.

A check in Python, standard library only:

import math
re, me, ne, Z = 2.8179403262e-15, 510.99895, 1.044e30, 10
L = math.hypot(262.0, 42.0*2.40)*1e-6
rate = 88/L
def f(b):
    Tm = 2*me*b*b/(1-b*b)
    return 2*math.pi*re**2*me*ne*Z**2/b**2*(1/30.0 - 1/Tm - b*b/Tm*math.log(Tm/30.0)) - rate
lo, hi = 0.1, 0.99
for k in range(100):
    m = (lo+hi)/2
    lo, hi = (m, hi) if f(m) > 0 else (lo, m)
print(m, 931.5*(1/math.sqrt(1-m*m) - 1))   # 0.4919, 138.4
