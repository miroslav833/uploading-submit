Key by hand. Period L = 6750 nm/139 = 48.56 nm. Per chain, in units of kT: interfaces 2 N g sqrt(chi/6)/L with the Helfand-Sapse factor g = (2/3)(aA^3 - aB^3)/(aA^2 - aB^2) = 0.6343 nm; brush stretching pi^2 h^2/(8 Nb a^2) for each block with h = L/4 and Nb = N/2, in total pi^2 L^2 (1/aA^2 + 1/aB^2)/(64 N) with 1/aA^2 + 1/aB^2 = 5.3584 nm^-2. Minimum over L: sqrt(chi/6) = pi^2 (1/aA^2 + 1/aB^2) L^3/(64 N^2 g) = 0.1522, chi = 0.139, so 0.14. chi N = 138. For equal segment lengths the expression becomes L = 2 (8 chi N/3 pi^4)^(1/6) a N^(1/2).

from math import *
aA, aB, N, L = 0.720, 0.540, 990, 6750/139
g = (2/3)*(aA**3 - aB**3)/(aA**2 - aB**2); S = 1/aA**2 + 1/aB**2
