The micrograph carries one value, the number of ripple periods between the two white bars. It is a simulated secondary-electron image (900 x 600 px, no scale bar) of vertical ripple crests whose local spacing wanders between about 7 and 10 px. that is 47 crests (four groups of ten and seven more), both bars included, so 46 periods: Lambda = 67.21 um/46 = 1461.09 nm.

Key by hand. lambda/Lambda = 800/1461.09 = 0.54754. The family lambda/(eta + sin theta) would need eta = 0.0475 and the normal-incidence rule eta = 0.548, both below 1, so no plasmon; the family Lambda = lambda/(eta - sin theta) gives eta = 0.54754 + 0.5 = 1.04754. eta^2 = 1.09733, eps = eta^2/(1 - eta^2) = -11.274. omega = 2 pi c/lambda = 2.3546e15 s^-1, eps0 m* omega^2/e^2 = 8.8542e-12 x 0.18 x 9.1094e-31 x (2.3546e15)^2/(1.6022e-19)^2 = 3.1355e26 m^-3 = 3.1355e20 cm^-3. N = (13.6 + 11.274) x 3.1355e20 = 7.80e21 cm^-3, that is 7.8 x 10^21 cm^-3.

The most tempting wrong answer is 7.1 x 10^21 cm^-3. It belongs to 47 periods, at which the period is a round 67.21/47 = 1.4300 um (or to the 47 crests taken as 47 periods): eta = 1.05944, eps = -9.169, N = 7.14e21. Other values: 45 periods 8.9e21, 44 periods 1.1e22, 48 periods 6.7e21; 42 periods or fewer give eta < 1 and no plasmon; the free-electron mass gives 4.3e22; dropping eps_b gives 3.5e21. A plasmon located numerically as the pole of the p-polarised Fresnel coefficient gives the same 7.80e21.

Check in a second (Python 3, standard library):
import math
def N(P, D=67.21e-6, lam=800e-9, th=30.0, eb=13.6, ms=0.18):
    eta = lam*P/D + math.sin(math.radians(th))
    eps = eta**2/(1 - eta**2)
    w = 2*math.pi*2.99792458e8/lam
    return (eb - eps)*8.8541878128e-12*ms*9.1093837e-31*w**2/1.602176634e-19**2/1e6   # cm^-3
print(N(46), N(45), N(47))   # 7.80e21, 8.90e21, 7.14e21
