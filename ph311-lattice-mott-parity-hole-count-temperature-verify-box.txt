By hand. Imaging loses atoms in pairs, so a dark site has n = 0, 2, 4, ... atoms. Atomic-limit weights with mu = U/2: w0 = 1, w1 = x = e^(beta U/2), w2 = 1, w3 = e^(-1.5 beta U), ... Then h = (2 + ...)/(2 + x + ...), x = 2(1 - h)/h = 9.858, beta U = 2 ln x = 4.577 (4.5765 with the n = 3, 4 terms). U/k_B = 6.62607e-34 x 420.0/1.380649e-23 = 20.157 nK, T = 20.157/4.5765 = 4.40 nK, so 4.4 nK.

The most tempting wrong answer is 7.4 nK, from taking every dark site as an empty site (P0 = h). Leaving doubly occupied sites out of the model (h = w0/(w0 + w1)) gives 6.3 nK. Any count from 166 to 173 gives 4.4; 160 gives 4.3 and 180 gives 4.5.

Check (Python, standard library):
import math
h = 170/1008; U = 6.62607015e-34*420.0/1.380649e-23*1e9
lo, hi = 0.1, 50.0
for _ in range(100):
    b = (lo + hi)/2; w = [math.exp(-b*(n*(n - 1)/2 - n/2)) for n in range(9)]
    lo, hi = (b, hi) if sum(w[0::2])/sum(w) > h else (lo, b)
print(round(U/b, 2))    # 4.4 nK
