By hand. 116 electrodes and two flanges make n = 117 gaps of 19.05 mm, 2.2289 m in all. The site needs J = 1.0 nA / 1.0e-13 m^2 = 1.0e4 A/m^2. Murphy-Good: J = (a/phi) F^2/t^2 exp(-v b phi^1.5/F), a = 1.541434e-6 A eV/V^2, b = 6.830890 eV^-1.5 V/nm, f = 1.439965 F/phi^2 (F in V/nm), v = 1 - f + (f/6) ln f, t = 1 + f/9 - (f/18) ln f. With phi = 4.33 eV, b phi^1.5 = 61.547 V/nm and the solution is F = 2.4475 V/nm (f = 0.188, v = 0.760, t = 1.038, exponent 19.10, prefactor 1.978e12 A/m^2); the exact barrier functions give 2.4415 V/nm. V_T = F x 117 x 19.05 mm / 1515 = 3.592 MV (3.601 MV with the approximate functions), so 3.6 MV. Counts of 116 to 118 gaps all give 3.6 MV.

The most tempting wrong answer is 4.6 MV, from the elementary Fowler-Nordheim equation without the image potential (v = t = 1), which needs F = 3.13 V/nm. 100 gaps give 3.1 MV, 120 gaps 3.7 MV.

A check in Python, standard library only:

import math
a, b, c, phi = 1.541434e-6, 6.830890, 1.439965, 4.33
J = 1.0e-9/1.0e-13
F = 2.5
for k in range(60):
    f = c*F/phi**2
    v, t = 1 - f + f/6*math.log(f), 1 + f/9 - f/18*math.log(f)
    F = v*b*phi**1.5/math.log(a/phi*(F*1e9)**2/t**2/J)
print(F, F*1e9*117*19.05e-3/1515/1e6)   # 2.4475 V/nm, 3.601 MV
