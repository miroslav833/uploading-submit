Key by hand. Flux per length Phi_L = 327 x 2.068e-15 Wb / 27.0e-6 m = 2.5046e-8 Wb/m. Thin strip in the critical state (Brandt and Indenbom 1993; Zeldov et al. 1994): H_c = J_c d / pi = 704.74 A/m (mu0 H_c = 0.88560 mT), core b = w / cosh y with y = H_a/H_c, and the field in the bands integrates to Phi_L = 2 mu0 H_c w ln cosh y. So ln cosh y = 2.5046e-8 / (2 x 0.88560e-3 x 7.00e-6) = 2.02008, cosh y = 7.5389, y = 2.7088, mu0 H_a = 0.88560 mT x 2.7088 = 2.399 mT, which is 2.4 mT. Counts from 319 to 336 give the same two digits.

Most tempting wrong answer: 2.1 mT, from reading the half width of the empty middle band (about 1.3 um) as the core b and solving b = w / cosh(H_a/H_c); the true core is 0.93 um, but the vortex density rises only as the square root of the distance from it, so the first clusters appear well outside it. A count about one fifth short gives 2.1 mT as well. The mean vortex density over the strip taken as mu0 H_a gives 1.8 mT.
