Key: n_alpha = 15.0 / (500 x 376 um^2) = 7.98e-5 um^-2. X_ext = pi n G^2 t^2 + (pi/3) I G^2 t^3 = 5.640e-4 t^2 + 1.0414e-5 t^3. X_ext = ln 2 at t = 28.39 min (terms 0.4547 and 0.2384). 28.4 min.
Most tempting wrong answer 28.1 min, from the thin beta strip at (17,96) counted as alpha (15.5); its boundary with (192,109) bows into that beta grain, so it is a later nucleus. Every grain as a site: 20.0 min. No beta term: 35.1 min.
Top-edge wedge (443,54) is beta by grey level (197). Beta count as a check: predicted 24.2 in the field, counted 25.5.

Check, standard-library Python:
import math; A = 500*376; n = 15/A; G = 1.5; I = 4.42e-6; a = math.pi*n*G*G; b = math.pi*I*G*G/3; t = 20.0
for _ in range(30): t -= (a*t*t + b*t**3 - math.log(2))/(2*a*t + 3*b*t*t)
print(round(t, 2))
