Key by hand. d = 106.9 um/143 = 747.55 nm (1337.7 per mm), lambda/d = 1.3778. First order: sin(theta_d) = 1.3778 - sin(32.50 deg) = 0.8405, theta_d = 57.2 deg, cos^2 = 0.2935. Grating pair (Treacy): phi2 = -lambda^3 G/(2 pi c^2 d^2 cos^3 theta_d) per pass and phi3 = -phi2 (3 lambda/(2 pi c)) [1 + (lambda/d) sin(theta_d)/cos^2(theta_d)], bracket = 4.946, 3 lambda/(2 pi c) = 1.6404 fs. Fibre: phi2 = 0.0236 x 150.0 = 3.540 ps^2, phi3 = 4.10e-5 x 150.0 = 0.00615 ps^3. Pair set to phi2 = -3.540 ps^2 (G = 81 mm in double pass): phi3 = 3.540 x 1.6404e-3 x 4.946 = 0.02872 ps^3, same sign as the fibre's. Left: 0.00615 + 0.02872 = 0.0349 ps^3, so 0.035.

Other values. Pair alone: 0.029. Pair's cubic term subtracted from the fibre's: 0.023. Littrow angle assumed: 0.022. Fibre alone: 0.0062. cos instead of cos^2 in the bracket: 0.024. A count of 139 grooves (1300 per mm): 0.029.

Short check (Python 3, standard library):
from math import *
d = 106.9e-6/143; lam = 1030.0e-9; c = 299792458.0
s = lam/d - sin(radians(32.50))
B = 1 + (lam/d)*s/(1 - s*s)
print(d, s, B, 150.0*(4.10e-5 + 0.0236*3*lam/(2*pi*c)*1e12*B))      # 7.4755e-07, 0.8405, 4.946, 0.03487
