Key by hand. With m = (cos phi, sin phi, 0), w = A phi'^2 - D phi' - mu0 Ms H cos phi. Zero field: pitch L0 = 4 pi A/D. In a field: soliton lattice with modulus kappa, period L = 4 kappa K sqrt(A/(2 mu0 Ms H)); lowest energy at kappa/E(kappa) = sqrt(H/Hc), with mu0 Ms Hc = pi^2 D^2/(32 A); so L/L0 = 4 K E/pi^2. H/Hc = 157.4/184.6 = 0.8527, sqrt = 0.9234, kappa = 0.9763, K = 2.940, E = 1.057, L/L0 = 1.260, L0 = 42.13 nm. D = 8 mu0 Ms Hc L0/pi^3 = 8 x 30274 J/m^3 x 42.13e-9 m/31.006 = 3.291e-4 J/m^2 = 0.33 mJ/m^2 (A = 1.10 pJ/m). With 106 or 108 lines: 0.332 or 0.326.

Most tempting wrong answer: 0.41 mJ/m^2, from taking the 53.08 nm spacing at 157.4 mT for the zero-field pitch (8 x 30274 x 53.08e-9/31.006). Assuming the 48 nm pitch of CrNb3S6 instead of reading the image gives 0.37 (that pitch would put 94 lines in the frame).

Check program (Python, standard library):
import math
def KE(k):
    a, b, c, s, p = 1.0, math.sqrt(1-k*k), k, 0.5*k*k, 1.0
    while abs(c) > 1e-16:
        a, b, c = (a+b)/2, math.sqrt(a*b), (a-b)/2
        s += p*c*c; p *= 2
    K = math.pi/(2*a); return K, K*(1-s)
lo, hi = 0.0, 1 - 1e-15
for _ in range(200):
    k = (lo+hi)/2
    if k/KE(k)[1] < math.sqrt(157.4/184.6): lo = k
    else: hi = k
K, E = KE(k)
L0 = 5680e-9/107/(4*K*E/math.pi**2)
print(k, 4*K*E/math.pi**2, L0*1e9, 8*164.0e3*0.1846*L0/math.pi**3*1e3)   # 0.97633 1.2600 42.13 0.3291
