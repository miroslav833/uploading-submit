Key: 31.2.29.17 Pn2_1m(0,b_1,0)s0s(0,0,g_2)000. The listed form stands in the attached verification notes in the part "table_excerpts.txt", which quotes the rows of basic space group 31, Bravais class 2.29, from the d = 2 part of the ISO(3+d)D table of Stokes, Campbell and van Smaalen (page 15), among them "31.2.29.17 Pn2_1m(0,β1,0)s0s(0,0,γ2)000", and the answer of the program FINDSSG for the four operators found below, which is the same entry.

By hand. Both Pb atoms follow u = U1 (a cos p1 + b sin p1) + U2 a cos p2, with p1 and p2 the phases of the waves on q1 = (alpha,0,0) and q2 = (0,alpha,0). The first wave is a cycloid, the second linear. The eight operations that exchange a and b would put a cycloid on q2 and are lost, so the fourfold axis goes. The n glide (x+1/2, y+1/2, -z) changes nothing and is kept. The mirror (-x+1/2, y, z) reverses a and q1: the cycloid goes to phase pi - p1 (x4 -> -x4 + 1/2) and the linear wave changes sign (x5 -> x5 + 1/2), kept. The mirror normal to b reverses the sense of the cycloid, lost, and with it the twofold axes along a and c and the inversion. The 2_1 axis along b, the product of the kept mirror and n, is kept. Group on the crystal axes: Pm2_1n, a setting of Pmn2_1 (No. 31), wave vectors along two axes, class 2.29. The table has the wave vectors along its b and c, so a' = c, b' = b, c' = -a and the symbol is Pn2_1m. Cycloid vector (along c'): 000. Linear-wave vector (along b'): shifts 0, 1/2, 1/2 for n, 2_1, m, and with the table's choice q2 + b* each shift gains the translation along b' (1/2, 1/2, 0), which gives s0s. Entry 31.2.29.17.

Most tempting wrong answer: a tetragonal entry such as 129.2.63.7 P4/nmm(a,0,0)0000(0,a,0)00s0, from keeping the fourfold axis because it relates q1 and q2. The two waves differ in kind, so no operation that exchanges a and b survives. Second: 31.2.29.16 Pn2_1m(0,b_1,0)000(0,0,g_2)000, with the shift of the mirror missed; FINDSSG gives that entry when the second wave is polarised along b. Third: the right group with the letters 0ss, or on the crystal axes as Pm2_1n(a,0,0)000(0,b,0)s00, neither of which is a printed row.

Check program (Python 3, standard library). It prints the fate of the eight operations with a diagonal point part (ra, rb are the signs on a and b):
from math import cos, sin, pi
u = lambda p1, p2: (cos(p1) + 0.6*cos(p2), sin(p1))
for name, ra, rb in [("1 and n", 1, 1), ("m normal to a, 2_1 along b", -1, 1), ("m normal to b, 2 along a", 1, -1), ("2 along c, inversion", -1, -1)]:
    ok = [(s1/2, s2/2) for s1 in (0, 1) for s2 in (0, 1) if all(abs(ra*u(p1, p2)[0] - u(ra*p1 + pi*s1, rb*p2 + pi*s2)[0]) + abs(rb*u(p1, p2)[1] - u(ra*p1 + pi*s1, rb*p2 + pi*s2)[1]) < 1e-9 for p1 in (0.3, 1.1) for p2 in (0.7, 2.9))]
    print(name, "kept, shifts %s" % (ok[0],) if ok else "lost")
Output: 1 and n kept with shifts (0, 0); m normal to a and 2_1 along b kept with shifts (0.5, 0.5); the other two pairs lost.

A69, 75-90 (2013) for the equivalence of settings; Pasero and Perchiazzi, Mineral. Mag. 60, 833-836 (1996) for the structure of PbFCl.
