Key by hand. lambda = 0.74483 m, e E0T lambda = 0.93103 MeV. Smooth approximation with p = beta gamma of the synchronous proton: dp/dn = G = e E0T lambda cos(phi_s)/mc^2 = 8.5934e-4, p0 = 0.07305, p1 = p0 + 112 G = 0.16929 (13.35 MeV). Deviations: dw/dn = a beta phi with a = e E0T lambda |sin(phi_s)| = 0.46552 MeV per radian, dphi/dn = -2 pi w/(mc^2 beta^2 gamma^3). Phase advance per cell [2 pi a/(mc^2 beta gamma^3)]^(1/2), 0.206 rad at the entrance and 0.134 rad at the exit. Phase of the oscillation at the exit Psi = 2 sqrt(kappa) [F(p1) - F(p0)] with F(p) = sqrt(p)(1 - p^2/10 + p^4/24) and kappa = 2 pi a/(mc^2 G^2) = 4221.4, so Psi = 18.213 rad and sin(Psi) = -0.595. Energy amplitude at the exit phi_0 [a mc^2/2 pi]^(1/2) (p0 p1)^(3/4) = 0.069813 x 8.338 MeV x 0.037084 = 21.59 keV. Energy deviation 21.59 x (-0.595) = -12.8 keV, so -13 keV. The two equations integrated numerically give -13.2 keV, and a gap-by-gap tracking without the smooth approximation gives -12.9 keV to first order and -12.8 keV with the full cosine.

Other values. 111 cells: -15 keV. 113 cells: -10 keV (-11 keV integrated). 60 cells, taken from a known machine: -16 keV. Non-relativistic kinematics: -10 keV. Entrance value of the amplitude kept: -6.8 keV; exit value: -24 keV. Early instead of late: +13 keV.

Short check (Python 3, standard library):
from math import *
mc2, lam, N = 938.272, 299.792458/402.5, 112
G = 1.250*lam*cos(radians(30))/mc2; a = 1.250*lam*sin(radians(30))
p0 = sqrt((1 + 2.5/mc2)**2 - 1); p1 = p0 + G*N; k = 2*pi*a/(mc2*G*G)
F = lambda p: 2*sqrt(p)*(1 - p*p/10 + p**4/24)
psi = sqrt(k)*(F(p1) - F(p0))
print(psi, radians(4.0)*sqrt(a*mc2/(2*pi))*(p0*p1)**0.75*sin(psi)*1e3)      # 18.213 rad, -12.8 keV
