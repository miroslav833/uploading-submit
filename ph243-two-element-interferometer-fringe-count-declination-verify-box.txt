Baseline: X = -7.93 sin 52.17 = -6.2634 m, Y = 65.14 m, Z = 7.93 cos 52.17 = 4.8636 m (Z drops out). Change of path difference = cos(dec) [X(cos HB - cos HA) - Y(sin HB - sin HA)] = cos(dec) [-6.2634 x (-0.088140) - 65.14 x 0.511198] = -32.7474 m x cos(dec). With lambda = c/1415.00 MHz = 0.211867 m: cos(dec) = 110 x 0.211867/32.7474 = 0.711673, dec = +44.63 deg, so 44.6 deg. With 109 and 111 fringes 45.2 and 44.1 deg.
