That is 127 lines, 7 to 9 px apart (the column of 996 px over 128 vortices is 7.78 px each), so the column holds N = 128 vortices.

Key by hand. k = pi N/L = 128 pi/120.00 = 3.3510/d, q = k - k_c = 3.3510 - 3.134 = 0.2170/d. xi_0^2 q^2 = 0.07182 x 0.04709 = 0.003383. Phase diffusion from the envelope equation: D = (xi_0^2/tau_0)(eps - 3 xi_0^2 q^2)/(eps - xi_0^2 q^2) = (0.07182/0.0379) x (0.0182 - 0.010148)/(0.0182 - 0.003383) = 1.8951 x 0.5433 = 1.0297 nu. Phase fixed at both ends: slowest mode sin(pi z/L), tau = L^2/(pi^2 D) = 14400/(9.8696 x 1.0297) = 1417.0 d^2/nu. With d^2/nu = 36.0 s: tau = 51011 s = 14.17 h, that is 14 h.

The most tempting wrong answer is 7.7 h. It follows from 120 vortices (square cells of height d, k = pi/d, almost on k_c): q = 0.0076/d, factor 0.9995, tau = 14400/(9.8696 x 1.8942) = 770.3 d^2/nu = 7.70 h. The same value follows at 128 vortices when the factor (eps - 3 xi_0^2 q^2)/(eps - xi_0^2 q^2) is left out. Other vortex numbers: 126 gives 10.1 h, 127 gives 11.6 h, 129 gives 19.7 h, 130 gives 39.0 h; fewer than 109 or more than 130 vortices lie outside the Eckhaus band. At 128 vortices: the factor eps/(eps - xi_0^2 q^2) alone on the time constant 9.5 h, the Eckhaus factor inverted 4.2 h, a slowest mode of wavelength L 3.5 h.

Check in a second (Python 3, standard library):
import math
kc, xi0, tau0, L, eps = 3.134, 0.268, 0.0379, 120.00, 0.0182   # units of d and d^2/nu
for N in (128, 120, 127, 129):
    q = math.pi*N/L - kc
    D = xi0**2/tau0*(eps - 3*xi0**2*q**2)/(eps - xi0**2*q**2)
    print(L**2/(math.pi**2*D)*36.0/3600)                      # hours: 14.17, 7.70, 11.59, 19.69
