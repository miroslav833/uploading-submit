The image is the only source of the wavelength. It is a simulated backlit strobe picture, 900 x 134 px (a 900 x 110 px frame and a strip under it), made for this question; the strip gives the centre-to-centre distance of drops A and B, 184.6 mm. Numbering pixel columns from 0, the main drops along the row lie at x = 81.2 + 7.60 j px (to within about 0.2 px); A is j = 0 and B is j = 97 (818.3 px), so there are 97 spacings. Every tenth drop from A is at 81.2, 157.3, 233.0, 309.1, 385.3, 461.1, 537.3, 613.1, 689.2 and 765.1 px. The fainter dots on the left part of the frame are satellites and are not counted.

Key by hand. lambda = 184.6 mm/97 = 1.90309 mm; v = lambda f = 6.3754 m/s. Volume and momentum flux carried over as the Poiseuille profile (momentum flux 4/3 rho ubar^2 pi Rn^2) flattens: Rj = (sqrt 3/2) x 0.1500 mm = 0.12990 mm. x = 2 pi Rj/lambda = 0.42889, I1/I0 = 0.20966, sqrt(gamma/(rho Rj^3)) = 5768.0 1/s, sigma = 5768.0 x sqrt(0.42889 x (1 - 0.42889^2) x 0.20966) = 1562.5 1/s. e-folding length v/sigma = 4.0803 mm; ln(129.90 um/0.35 um) = 5.9166; unbroken length 4.0803 x 5.9166 = 24.14 mm, which rounds to 24 mm. The complex-wavenumber solution in the laboratory frame gives 24.17 mm.

The most tempting wrong answer is 28 mm, from taking the bore radius 0.1500 mm as the column radius. A 2.0 mm wavelength (92 spacings) gives 27 mm; the drive taken at the fastest mode x = 0.697 without the image gives 12 mm; stopping at the e-folding length gives 4.1 mm. Other counts: 96 spacings give 24.6 mm, 98 give 23.7 mm, 94 give 25.5 mm, 100 give 22.9 mm.

Check program (Python 3, standard library):
import math
def I(n, x): return sum((x/2)**(2*j + n)/(math.factorial(j)*math.factorial(j + n)) for j in range(30))
gam, rho, f, lam, xi0 = 0.0728, 998.2, 3350.0, 184.6e-3/97, 0.35e-6
R = math.sqrt(3)/2*0.1500e-3
x = 2*math.pi*R/lam
s = math.sqrt(gam/(rho*R**3)*x*(1 - x*x)*I(1, x)/I(0, x))
print(lam*f/s*math.log(R/xi0)*1e3)   # 24.14 (mm)
