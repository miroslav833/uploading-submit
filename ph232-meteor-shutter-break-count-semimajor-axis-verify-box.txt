Key by hand. Time 123/50.00 = 2.460 s, speed v = 57.60/2.460 = 23.415 km/s. Far from the Earth vg = sqrt(23.415^2 - 11.12^2) = 20.606 km/s. Zenith attraction: tan(dz/2) = (v - vg)/(v + vg) tan(51.0/2) = 0.06381 x 0.47698 = 0.03044, dz = 3.487 deg, corrected zenith distance 54.487 deg. cos(eps) = cos 54.487 cos 58.0 + sin 54.487 sin 58.0 cos 128.1 = -0.11811. vh^2 = 29.78^2 + 20.606^2 + 2 x 29.78 x 20.606 x 0.11811 = 1456.39, vh = 38.163 km/s. a = 1/(2 - 1456.39/29.78^2) = 1/(2 - 1.64221) = 2.7950 AU. Answer 2.8 AU. The result is sensitive to the count: 122 periods give 2.88 AU and 124 give 2.72 AU.

Most tempting wrong answers. 57.60 km x 50.00 per second is 2880 km/s divided by the number of periods, which is a round 24.0 km/s for 120 periods, 22.5 km/s for 128 and 20.0 km/s for 144; taking the number of periods from one of these in place of the count gives 3.1, 2.5 or 1.9 AU. No correction for the Earth's attraction gives 3.7 AU; the speed corrected but the radiant left where it was seen gives 2.4 AU.

Check program (Python 3, standard library; prints 23.415 20.606 54.487 38.163 2.795):

import math
N, f, L, z, vesc, zA, dAz, VE = 123, 50.00, 57.60, 51.0, 11.12, 58.0, 128.1, 29.78
v = L * f / N
vg = math.sqrt(v * v - vesc * vesc)
zg = math.radians(z) + 2 * math.atan((v - vg) / (v + vg) * math.tan(math.radians(z) / 2))
c = math.cos(zg) * math.cos(math.radians(zA)) + math.sin(zg) * math.sin(math.radians(zA)) * math.cos(math.radians(dAz))
vh2 = VE * VE + vg * vg - 2 * VE * vg * c
print(round(v, 3), round(vg, 3), round(math.degrees(zg), 3), round(math.sqrt(vh2), 3), round(1 / (2 - vh2 / VE ** 2), 4))
