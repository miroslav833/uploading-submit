Key by hand. Lambda = 1.982 + 2.057 = 4.039 nm. Iron 2/a^3 = 8.4913e28 m^-3, rho_Fe = 8.0243e-6, rho_Si = 2.0720e-6, contrast 5.9523e-6, magnetic rho_m = 2.695 fm x 2.20 x 8.4913e28 = 5.0345e-6 (all per square angstrom). A neutron with spin along the magnetisation has its moment against the field and sees rho_Fe + rho_m in the core. Magnetic core 1.982 - 0.600 = 1.382 nm. Bilayer amplitude r = (2 Lambda^2/pi)[5.9523e-6 sin(pi 1.982/4.039) + 5.0345e-6 sin(pi 1.382/4.039)] = 1038.55 x 10.3779e-6 = 0.010778. N r = 188 x 0.010778 = 2.0263, T = 1/cosh^2(2.0263) = 1/3.85873^2 = 0.0672, which is 6.7 per cent. A full characteristic-matrix calculation of the layer profile gives 6.725 per cent.

Most tempting wrong answer: 92 per cent, from giving the spin-parallel neutron rho_Fe - rho_m (moment taken along the spin). Spreading the reduced moment over the whole iron layer gives 9.5 per cent; ignoring the dead skins gives 5.3 per cent.

import math
n = 2 / 2.8665**3
dn = 9.45e-5 * n - 4.149e-5 * 4.994e-2

print(100 / math.cosh(188 * r)**2)   # 6.716 per cent
