Key: BA 24:0;5bH;3aOH,7bOGlcNAc;24COOH

You can read the key in Liebisch et al., J. Lipid Res. 61, 1539-1555 (2020), open access, Table 6B, row "Ursodeoxycholic acid 7beta-N-acetylglucosaminide (UDCA-GlcNac)", column "Full Structure Level". The attached notes reproduce the whole table, and the first script prints the row on the output line "Full structure level (key)".

The paper's rules give the same string by hand. A bile acid takes the class BA. Cholan-24-oic acid has 24 carbons and no C=C, and the acid is written as a group, so the count is 24:0. The 5beta ring fusion is 5bH. Ring oxygen functions carry a or b, here 3aOH and 7bOGlcNAc (a sugar on a ring oxygen, as in 3bOGlc for cholesteryl glucoside), and the row joins them with a comma, keeping the semicolon for a change of group type (testosterone has 17bOH;3oxo). The free acid is 24COOH. Sibling rows come out the same way, lithocholic acid as BA 24:0;5bH;3aOH;24COOH and glycochenodeoxycholic acid as BA 24:0;5bH;3aOH,7aOH;24COG.

The most tempting wrong answer is ST 24:1;O4;GlcNAc. It is the Species level entry of the same row (ST 24:1;O4;HexNAc, which is 24 carbons, one double-bond equivalent for the acid C=O, four oxygens and one N-acetylhexosamine) with the sugar named. It carries no positions and no stereochemistry, so it is not the Full structure level.

These two lines of Python 3 (standard library) put the parts together and print the key.
ring = [(3, 'a', 'OH'), (7, 'b', 'OGlcNAc')]
print('BA 24:0;5bH;' + ','.join('%d%s%s' % g for g in ring) + ';24COOH')

The sources are Liebisch et al., J. Lipid Res. 61, 1539 (2020) and Marschall et al., J. Clin. Invest. 89, 1981 (1992).
