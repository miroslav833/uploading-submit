Key by hand. 1/B_Q - 1/B_P = 2.8571 - 0.5000 = 2.3571 per tesla, F = 137/2.3571 = 58.12 T. Ellipsoid of revolution, field at 39.0 degrees from its axis: m_c = sqrt(mt^2 ml/(ml cos^2 + mt sin^2)) = sqrt(0.045^2 x 0.620/0.3923) m_e = 0.05657 m_e. Onsager with A = 2 pi m_c E_F/hbar^2: E_F = hbar e F/m_c = 118.9 meV. Density with two electrons per orbital state: n = (2 E_F)^(3/2) sqrt(mt^2 ml)/(3 pi^2 hbar^3) = 6.600e24 m^-3 = 6.6e18 cm^-3. The density changes by 1.1 per cent per cycle (136 cycles 6.53e18, 138 cycles 6.67e18).

from math import *
hb, e, me = 1.054571817e-34, 1.602176634e-19, 9.1093837015e-31
mt, ml, th = 0.04500, 0.620, radians(39.0); F = 137/(1/0.3500 - 1/2.000)
mc = sqrt(mt*mt*ml/(ml*cos(th)**2 + mt*sin(th)**2)); EF = hb*e*F/(mc*me)
print(F, mc, EF/e, (2*EF*me)**1.5*sqrt(mt*mt*ml)/(3*pi**2*hb**3)*1e-6)   # 58.12, 0.05657, 0.11893, 6.600e18
