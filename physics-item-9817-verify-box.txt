Key by hand. One layer is 0.600/5.612 + 1.200/413.1 = 0.106914 + 0.002905 = 0.109819 X0; depth T = 188 x 0.109819 = 20.646 X0. Critical energy (0.106914 x 7.43 + 0.002905 x 93.11)/0.109819 = 9.696 MeV. t_max = ln(30000/9.696) - 0.5 = 7.5372, a = 1 + 0.5 x 7.5372 = 4.7686, bT = 10.323. Leakage = Gamma(a, bT)/Gamma(a) = 0.32209/17.040 = 0.01890, which is 1.9 per cent.

Most tempting wrong answer: 3.0 per cent, from the photon constant +0.5 in t_max in place of -0.5 for an electron. Weighting the critical energies by thickness in mm gives 0.66 per cent.

Check program (Python with SciPy):

import math
from scipy.special import gammaincc
tp, ts = 0.600 / 5.612, 1.200 / 413.1
Ec = (tp * 7.43 + ts * 93.11) / (tp + ts)
a = 1 + 0.5 * (math.log(30000 / Ec) - 0.5)
print(100 * gammaincc(a, 0.5 * 188 * (tp + ts)))   # 1.890 per cent
