Key by hand. Sun-synchronous node rate 2 pi/(686.980 x 86400 s) = 1.058576e-7 rad/s; Mars turns at 2 pi/88642.66 s = 7.088218e-5 rad/s; nodal day 2 pi/(7.088218e-5 - 1.058576e-7) = 88775.24 s, the sol. Nodal period T_N = 13 x 88775.24/161 = 7168.187 s. Secular J2 rates (Kozai 1959): Omega' = -(3/2) n J2 (R/a)^2 cos i, u' = omega' + M' = n [1 + (3/2) J2 (R/a)^2 (4 cos^2 i - 1)]. Iterating from the Keplerian a = 3820.00 km: cos i = -0.05209, factor 1 - 2.293e-3, a = 3814.16 km; again cos i = -0.05181, factor 1 - 2.3007e-3, a = 3814.14 km, i = 92.97 deg. Height a - R = 417.9 km, which is 418 km.

Most tempting wrong answer: 311 km, from 168 passes, taken as fourteen tracks in every 30 degree interval (the intervals hold 13 or 14). With the right count, a nodal period equal to the Keplerian period gives 424 km and a repeat in sidereal days gives 414 km.

Check program (Python, standard library):

import math
GM, R, J2 = 4.282837e13, 3396.2e3, 1.9555e-3
Os = 2 * math.pi / (686.980 * 86400); w = 2 * math.pi / 88642.66
TN = 13 * 2 * math.pi / (w - Os) / 161
a = (GM * (TN / (2 * math.pi))**2)**(1 / 3)
for _ in range(20):
    n = math.sqrt(GM / a**3); k = 1.5 * J2 * (R / a)**2; c = -Os / (n * k)
    a = (GM / ((2 * math.pi / TN) / (1 + k * (4 * c * c - 1)))**2)**(1 / 3)
print((a - R) / 1e3, math.degrees(math.acos(c)))   # 417.94 km, 92.97 deg
