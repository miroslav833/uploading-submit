The spacing is 8.37 px throughout and a slit takes 0.40 of it. Ruler check: from the tenth line to the eightieth is 586 px, 8.37 px per spacing, and the first and last line are 720 px apart, 86.0 spacings, so 87 slits.

Key by hand. p = 45.00 mm/87 = 0.5172 mm, p/L = 6.990e-4 rad = 144.2 arcsec. The response of two identical gratings to a point source is the autocorrelation of one slit train, so harmonic k has the amplitude 2 sin^2(pi k a/p)/(pi k)^2; with a/p = 2/5 the third is 0.04244 of the first. A Gaussian source of full width at half maximum s multiplies harmonic k by exp(-pi^2 k^2 s^2 L^2/(4 ln2 p^2)), and a steady background changes only the constant. So 0.0135 = 0.04244 exp(-2 pi^2 s^2 L^2/(ln2 p^2)), s L/p = sqrt(ln2 x 1.1454/(2 pi^2)) = 0.2006 and s = 0.2006 x 144.2 = 28.9 arcsec. Answer 29 arcsec. With 86 or 88 slits the value is 29.3 or 28.6.

Most tempting wrong answer: 39 arcsec, from the point-source ratio 1/9 that holds for slits half a period wide: s L/p = sqrt(ln2 x ln(0.1111/0.0135)/(2 pi^2)) = 0.272. A period of exactly 0.500 mm (90 slits) gives 28 arcsec.

Check program (Python, standard library):

import math
W, L, N, R, q = 45.00e-3, 0.7400, 87, 0.0135, 0.4
R0 = math.sin(3 * math.pi * q) ** 2 / (9 * math.sin(math.pi * q) ** 2)
s = (W / N / L) * math.sqrt(math.log(2) * math.log(R0 / R) / (2 * math.pi ** 2))
print(R0, s * 180 * 3600 / math.pi)      # 0.042441, 28.915 arcsec
