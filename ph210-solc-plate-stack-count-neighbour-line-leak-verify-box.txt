The answer is not in a paper. It follows from the number of plates in the pile, which only the photograph shows, and from the Jones calculus of the folded Solc filter in the citations above. The uploaded notes contain the scripts and their output.

Key by hand. T = [tan(2 rho) cos(chi) sin(N chi)/sin(chi)]^2 with cos(chi) = cos(2 rho) |sin(Gamma/2)|. At D2: Gamma = 2 pi x 3466.65/766.701 = 9.04303 pi, |sin(Gamma/2)| = 0.997717, cos(2 rho) = 0.999770, cos(chi) = 0.997487, chi = 0.070903 rad. N chi = 77 x 0.070903 = 5.45952 rad, sin = -0.73364. T = (0.021436 x 0.997487 x 0.73364/0.070843)^2 = 0.0490. Answer 0.049.

Most tempting wrong answer. The matched plate number 45 deg/0.614 deg = 73.3, taken as 73 plates, gives 0.073. 76 or 78 plates give 0.055 or 0.043.

Check program (Python 3, standard library; prints 9.04303, 0.070903, 5.45952, 0.04903):

import math
N, rho = 77, math.radians(0.614)
G = 2 * math.pi * 3466.65 / 766.701
chi = math.acos(math.cos(2 * rho) * abs(math.sin(G / 2)))
T = (math.tan(2 * rho) * math.cos(chi) * math.sin(N * chi) / math.sin(chi)) ** 2
print(G / math.pi, chi, N * chi, T)
