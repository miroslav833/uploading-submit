Key: 341 rpm. It stands in the attached notes in the first section (output line 'KEY N = 341.05 rpm') and in the second section (bisection, 341.05 rpm). By hand, with Takahashi and Iguchi, ISIJ International 46 (8), 1143-1148 (2006): Eq. (5) T_c = 60 D^2 H_w/(pi N D_I^3); Eq. (7) Re_I = pi N D_I^2/(60 nu); Eq. (11) for the real-type impeller, (T_fe/T_c) Re_I^(1/3) (D_c/R)^(1/4) = 1050 (D_I/D)^(3/4), R the vessel radius. At 300 rpm: T_c = 60 x 0.09 x 0.3/(pi x 300 x 0.08^3) = 3.357 s, Re_I = pi x 300 x 6400/(60 x 0.893) = 1.1258e5, T_fe = 3.357 x 1050 x (80/300)^0.75 x Re_I^(-1/3) x (50/150)^(-0.25) = 35.65 s. T_fe varies as N^(-4/3), so N = 300 (35.65/30.05)^0.75 = 341 rpm. The most tempting wrong answer is 545 rpm, from the coefficient 1960 that the paper gives for its other impellers (Eq. (10)). Check program (Python, standard library): import math; f=lambda n: 60*0.3**2*0.3/(math.pi*n*0.08**3)*1050*(80/300)**0.75*(math.pi*n*80**2/(60*0.893))**(-1/3)*(50/150)**-0.25; print(round(f(300),2), round(300*(f(300)/30.05)**0.75,2)). It prints 35.65 and 341.05. Source: the paper named above, Eqs. (5), (7), (10), (11), pp. 1145-1147, https://www.jstage.jst.go.jp/article/isijinternational/46/8/46_8_1143/_article.
