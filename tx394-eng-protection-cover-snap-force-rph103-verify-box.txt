Key: 5.9e2 kN (590.6 kN before rounding). In the attached notes it is the line 'KEY' of the first script and the 'time integration' line of the second. DNV-RP-H103 (April 2011), Section 4.7: F_snap = v_snap sqrt(K (M + A33)) (4.7.2.1); v_snap = v_ff + C v_r (4.7.3.1); v_r = v_c + sqrt(v_ct^2 + v_w^2) (4.7.3.2); v_c = 0, the typical lowering velocity and, for retrieval, a typical hoisting velocity, the highest v_snap kept, with v_c = 0.50 m/s when the typical velocity is unknown (4.7.3.3 and its guidance note); C = 1 below v_ff/v_r = 0.2, cos[pi(v_ff/v_r - 0.2)] from 0.2 to 0.7, 0 above 0.7 (4.7.3.4); v_ff = sqrt(2 F_static/(rho Ap CD)) (4.7.3.5). By hand: F_static = (10000 - 1025 x 4.20) 9.81 = 55868.0 N, v_ff = 0.64259 m/s; sqrt(0.45^2 + 0.75^2) = 0.87464; recovery v_r = 1.37464, ratio 0.46746, C = cos(0.26746 pi) = 0.66728, v_snap = 1.55986 m/s (lowering 1.37836, zero 0.64259). k_line = 85e9 x 1.04954e-3/60 = 1.48685e6 N/m, K = 1/(1/1.48685e6 + 1/1.5e6) = 7.46699e5 N/m, sqrt(K x 192000) = 3.78637e5, F_snap = 5.90621e5 N. Clause 4.7.3.4 as printed (April 2011, p. 73; unchanged in the February 2014 edition): C = 1 for v_ff < 0.2 v_r; C = cos[pi (v_ff/v_r - 0.2)] for 0.2 v_r < v_ff < 0.7 v_r; and C = 0 for v_ff > 0.7 v_r. Guidance note of 4.7.3.3: If the typical hoisting/lowering velocity is unknown, a value of v_c = +-0.50 m/s may be applied. Most tempting wrong answers: 6.9e2 or 7.5e2 kN from a cosine stretched to vanish at a ratio of 1.0 or 1.8 instead of 0.7; 5.2e2 kN from recovering at the lowering speed. Check program (Python, standard library): import math; vff=(2*(10000-1025*4.2)*9.81/(1025*110*2.4))**.5; vr=.5+math.hypot(.45,.75); C=math.cos(math.pi*(vff/vr-.2)); K=1/(60/(85e9*.58*math.pi*.048**2/4)+1/1.5e6); print(round((vff+C*vr)*(K*192000)**.5/1e3,1)) prints 590.6. Source: DNV-RP-H103, April 2011, Section 4.7 (pp. 72 to 74), free PDF from rules.dnv.com.
