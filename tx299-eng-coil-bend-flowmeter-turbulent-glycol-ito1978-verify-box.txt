Itō and Miyakawa 1978 (Bulletin of the JSME 21, 1268-1276): Q = C_d pi a^2 sqrt(2gh) (Eq. 5); R_h = sqrt(2gh) d/nu (Eq. 20); R_e = C_d R_h (Eq. 22); R_ec = 2.0 (a/R)^0.32 x 10^4 (Eq. 39); turbulent Eq. (43): C_d (a/R)^1/2 = 0.512 + 0.78 (a/R)^5/2 - 0.070 [R_h (a/R)^3/2]^-1/5 for 7 < R/a < 28, R_ec/C_d < R_h < 3e5. Here w_m = 3.71030 m/s, R_e = 8927.04 > R_ec = 7139.9, so turbulent; (a/R)^1/2 = 0.2. Solving Eq. (43) with R_h = R_e/C_d: C_d = 2.38392, R_h = 3744.68 (inside the range). p_o - p_i = rho w_m^2/(2 C_d^2) = 1082 x 3.71030^2/(2 x 2.38392^2) = 1310.5 Pa; Eq. (44) gives 1311.8 Pa, the same 1.31 kPa.
