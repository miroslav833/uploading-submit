Each guide line lies on the crest of a bright fringe, so the 290.0 micrometres hold 147 periods.

Key by hand. a = 290.0 um/147 = 1.9728 um. The potential V0 sin^2(pi x/a) has the wavenumber pi/a, so E_R/h = h/(8 m a^2) = 1826.7 Hz and s = 31500/1826.7 = 17.244, sqrt(s) = 4.1526. Deep lattice, leading order: width of the lowest band 4J = (16/sqrt(pi)) E_R s^(3/4) exp(-2 sqrt(s)), so J/h = 2.2568 x 1826.7 x 8.462 x 2.472e-4 = 8.62 Hz, so 8.6.

Other values. Recoil energy with the wavenumber 2 pi/a: 780. Band width 4J: 34. J/hbar: 54. Mass of 6Li: 17. Overlap of Gaussian Wannier functions in place of the band width: 1.6. A count of 145 fringes (period 2.000 um): 7.6. The exact band width at this depth gives 7.6 Hz for J; the question asks for the leading term.

Short check (Python 3, standard library):
from math import *
a = 290.0e-6/147; ER = 6.62607e-34/(8*7.016003*1.660539e-27*a*a); s = 31.50e3/ER
print(a, ER, s, 4/sqrt(pi)*ER*s**0.75*exp(-2*sqrt(s)))      # 1.9728e-06, 1826.7, 17.244, 8.624
