By hand. Misfit component of a 60 deg dislocation: a/(2 sqrt2) = 0.19987 nm. Relaxation along [110]: 78 x 0.19987/12140 = 1.2842e-3, residual strain e1 = 1.2842e-3 - 2.052e-3 = -7.678e-4. Along [-110]: 25 x 0.19987/8483 = 5.890e-4, e2 = -1.4630e-3. In the <110> axes with sigma_zz = 0: Q11 = (C11 + C12)/2 + C44 - C12^2/C11 = 120.28 GPa, Q12 = (C11 + C12)/2 - C44 - C12^2/C11 = 2.48 GPa. sigma_[110] = Q11 e1 + Q12 e2 = -95.98 MPa, i.e. -96 MPa. Only 78 lines on AB give -96 (77 give -98, 79 give -94); 17 to 33 on CD keep it.

The most tempting wrong answer is -94 MPa: the (001) biaxial modulus 122.8 GPa times e1. Cube-axis stiffness gives -110; the whole Burgers vector as misfit component gives +60.

A check in Python, standard library only:

import math
a, f, C11, C12, C44 = 0.56533, 2.052e-3, 117.9, 53.6, 58.9
b = a/(2*math.sqrt(2))
e1, e2 = 78*b/12140 - f, 25*b/8483 - f
Q11 = (C11 + C12)/2 + C44 - C12**2/C11
Q12 = (C11 + C12)/2 - C44 - C12**2/C11
print(1000*(Q11*e1 + Q12*e2))   # -95.98 MPa
