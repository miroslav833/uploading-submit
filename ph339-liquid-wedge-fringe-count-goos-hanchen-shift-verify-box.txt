Key by hand. Double pass: 109 x 0.6328/(2 (n2 - 1)) = 76.15 um, n2 = 1.452890. n1 sin 62.00 deg = 1.521407, q = sqrt(1.521407^2 - 1.452890^2) = 0.451430. s-polarised total reflection, phi = -2 arctan(q/(n1 cos theta)); Artmann shift along the surface D = -d phi/d k_x = 2 sin theta/(k0 q cos theta) = 2 x 0.882948/(9.92918 x 0.451430 x 0.469472) = 0.839 um, so 0.84 um.
Most tempting wrong answers: a miscount (108 fringes give 0.815 um, 110 give 0.865 um, about 100 from one mid-cell spacing give 0.68 um), the shift across the beam D cos theta (0.39 um), p polarisation (0.96 um), and a single pass (n2 = 1.906, no total reflection).
Check in seconds (Python, standard library):
import math
n2=1+109*0.6328/(2*76.15); t=math.radians(62.0); n1=1.72310
q=math.sqrt((n1*math.sin(t))**2-n2**2)
print(2*math.sin(t)/(2*math.pi/0.6328*q*math.cos(t)))   # 0.839 um
