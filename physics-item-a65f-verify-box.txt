Key by hand. xi = 1 - (121/24) ln(13/11) = 0.15777. n = 1.700 x 6.02214e23/12.011 = 8.5236e22 per cm^3, Sigma_s = 0.40487 per cm, Sigma_tr = 0.40487 x (1 - 2/36) = 0.38238 per cm. tau = ln(2.45e6/1.46)/(3 xi Sigma_s Sigma_tr) = 14.3332/0.073277 = 195.61 cm^2. Ratio exp(-44.801^2/(4 x 195.61)) = exp(-2.5652) = 0.0769, which is 0.077.

Most tempting wrong answer: 0.066, from leaving out the transport correction. Writing the Gaussian as exp(-x^2/(2 tau)) gives 0.0059.

Check program (Python, standard library):

import math
A = 12.0
xi = 1 + (A - 1)**2 / (2 * A) * math.log((A - 1) / (A + 1))
Ss = 1.700 * 6.02214076e23 / 12.011 * 4.750e-24
tau = math.log(2.45e6 / 1.46) / (3 * xi * Ss * Ss * (1 - 2 / (3 * A)))
print(math.exp(-(107 * 0.4187)**2 / (4 * tau)))   # 0.0769
